## kool proxy aliases

List configured internal proxy aliases for the current project

### Synopsis

List configured internal Docker DNS aliases for the current project. This does not inspect running containers or contact Caddy.

```
kool proxy aliases [flags]
```

### Options

  -h, --help   help for aliases
